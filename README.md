\# AutoLoc



\## Présentation

AutoLoc est une plateforme de gestion de location

de véhicules multi-agences.



\## Technologies

\- Java 17

\- Spring Boot 4.0.8

\- Maven

\- MySQL 8

\- Spring Data JPA

\- Lombok



\## Acteurs

\- Client

\- Agent d'agence

\- Responsable d'agence

\- Administrateur



\## Base de données

Nom : autoloc\_db
