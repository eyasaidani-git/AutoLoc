# \# AutoLoc

# 

# \## Présentation

# 

# AutoLoc est une plateforme de gestion de location de véhicules multi-agences.

# 

# L'objectif du projet est de développer une application permettant de gérer les opérations liées à la location de véhicules au sein de plusieurs agences.

# 

# \## Acteurs

# 

# Les principaux acteurs identifiés sont :

# 

# \- Client

# \- Agent d'agence

# \- Responsable d'agence

# \- Administrateur
